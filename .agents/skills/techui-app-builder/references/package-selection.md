# TechUI 产品包选择

参考入口：[TechUI 官方文档](https://techui.net/#/docs)。本页最近核对日期：2026-08-30。

## 选择矩阵

| 产品包 | 适合场景 | 选择边界 |
| --- | --- | --- |
| `@techui/base` | 常规 Vue 应用、表单、布局、导航、数据展示与反馈 | 默认首选；需求没有明确后台、科幻或 Prime 能力时使用 |
| `@techui/admin` | 管理后台、工作台、菜单与路由驱动的后台外壳 | 仅在需要 Admin 产品能力时选择，不因页面“看起来像后台”就自动引入复杂权限体系 |
| `@techui/scifi` | 数据可视化大屏、未来感界面、动态 SVG 与科幻装饰 | 用于明确的科幻视觉与展示场景；普通业务页面仍优先 Base |
| `@techui/prime` | 已获得合法授权的综合产品或评估工程 | 不作为默认选择；不得提交授权文件、令牌或其他敏感材料 |

## 决策规则

1. 选择能够覆盖需求的最小产品包，不默认使用 Prime。
2. 扩展已有应用时优先保持它当前的产品包，除非公开能力确实不足。
3. 同时出现多类需求时，先核对目标产品包的官方注册范围；不要假设所有组件都能跨包导入。
4. 组件是否存在、如何导入、是否需要样式或额外依赖，以当前官方文档和安装包导出为准。
5. 不在一个最小应用中同时安装多个用途重叠的 TechUI 产品包来“碰运气”。

## 功能开关

- `features.echarts`：仅在应用实际使用 ECharts 能力并已提供真实 ECharts 对象时开启。
- `features.advanced`：仅在使用对应高级组件且官方文档要求时开启。
- Prime 的 `features.admin`：只有综合应用确实需要 Admin 能力时开启。

不要仅为未来可能使用而开启功能；启用前核对对应 Starter、官方文档和当前版本声明。
